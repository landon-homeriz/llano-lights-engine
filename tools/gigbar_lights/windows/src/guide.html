Set up Llano Lights, step by step

Set up page Go to the Live screen

Do these in order. Each step checks itself where it can, and tells you what to do if it didn't work. The same steps, with pictures of the cables, are in the room Set up Llano Lights, start to finish on llano.app.

Checking...
All set. At the venue: line up the lights (Set up, Line up my lights). On the night: 1. Open Llano Lights and press Live show. 2. Open Mixxx and click the first button at the top of the Auto DJ page (Enable Auto DJ): the music starts and the lights follow. 3. Each time a moment is over, click the second button (Fade Now) in Mixxx. The run sheet (Shows, Open the run sheet) lists every press.
